# فونٹ کی تنصیب — Jameel Noori Nastaleeq

اس ویب سائٹ کا بنیادی اردو فونٹ **Jameel Noori Nastaleeq** رکھا گیا ہے۔

## اہم نوٹ

یہ فونٹ فائل اس پروجیکٹ میں شامل نہیں کی گئی، کیونکہ اس کی لائسنسنگ کی حیثیت واضح طور پر معلوم نہیں اور غیر لائسنس یافتہ فونٹ فائل تقسیم کرنا مناسب نہیں۔

## فونٹ فعال کرنے کا طریقہ

1. Jameel Noori Nastaleeq فونٹ کی قانونی/لائسنس یافتہ کاپی حاصل کریں۔
2. اسے ویب فونٹ فارمیٹ (`.woff2`) میں تبدیل کریں (اگر ضرورت ہو تو کسی معتبر آن لائن یا مقامی فونٹ کنورٹر کا استعمال کریں)۔
3. فائل کا نام تبدیل کریں: `JameelNooriNastaleeq.woff2`
4. اسے اسی فولڈر میں رکھیں: `assets/fonts/JameelNooriNastaleeq.woff2`
5. صفحہ ریفریش کریں — `assets/css/style.css` میں موجود `@font-face` قاعدہ خود بخود اس فائل کو لوڈ کر لے گا۔

## اگر فونٹ فائل موجود نہ ہو

ویب سائٹ اس صورت میں بھی مکمل طور پر قابلِ استعمال اور قابلِ مطالعہ رہتی ہے۔ براؤزر خودکار طور پر متبادل (fallback) فونٹس استعمال کرے گا:

```
"Jameel Noori Nastaleeq", "Noto Nastaliq Urdu", serif
```

`Noto Nastaliq Urdu` عام طور پر صارف کے آپریٹنگ سسٹم یا گوگل فونٹس کے ذریعے دستیاب ہوسکتا ہے، اور serif حتمی متبادل کے طور پر ہر برداؤزر میں موجود ہوتا ہے۔
