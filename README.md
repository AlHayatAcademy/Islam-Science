# اسلام اور سائنس — Islam & Science Learning Hub

ایک مکمل، خالص جامد (static) اردو تعلیمی ویب سائٹ جو اسلام اور سائنس کے تعلق کو 15 موضوعات کی صورت میں پیش کرتی ہے۔

## 1. پراجیکٹ کا مقصد

یہ ویب سائٹ طلبہ کو اسلامی علمی روایت اور جدید سائنسی فہم کے باہمی تعلق سے، متوازن، مصدقہ اور تنقیدی انداز میں روشناس کرانے کے لیے بنائی گئی ہے۔ تمام مواد 15 اپ لوڈ کردہ Word دستاویزات پر مبنی ہے۔ کوئی حوالہ، آیت، حدیث، سائنسی دعویٰ یا اقتباس از خود شامل نہیں کیا گیا۔

## 2. اہم خصوصیات

- 15 مکمل موضوعاتی صفحات، ہر ایک میں: مضمون، تعلیمی مقاصد، اہم تصورات، کلیدی اصطلاحات، تفصیلی سوال، 7 مختصر سوالات و جوابات، 20 MCQs، دہرائی کا خلاصہ، منتخب مراجع، متعلقہ موضوعات، اور پیج نیویگیشن۔
- سائٹ کے سطح پر انٹرایکٹو MCQ کوئز انجن (پریکٹس اور امتحان موڈ، سکور، جائزہ)۔
- مختصر سوالات، مقالہ سوالات اور دہرائی کے لیے علیحدہ، فلٹر اور تلاش کے ساتھ صفحات۔
- ہر موضوع کے تفصیلی سوال کے لیے ایک مکمل ~1500-2000 الفاظ کا امتحانی طرز کا جواب (essay-questions.html پر "مکمل امتحانی جواب" کے بٹن سے قابلِ دید)۔
- مکمل کلائنٹ سائیڈ سرچ (موضوعات، مضامین، MCQs، مختصر سوالات، مقالہ سوالات، دہرائی — سب میں بیک وقت)۔
- مکمل RTL اردو انٹرفیس، Jameel Noori Nastaleeq فونٹ سپورٹ (فال بیک کے ساتھ)۔
- مکمل responsive ڈیزائن (320px تا 1440px)، پرنٹ فرینڈلی صفحات، بنیادی ایکسیسبیلیٹی (skip link، فوکس اسٹیٹس، سیمنٹک HTML)۔
- بنیادی SEO: میٹا ٹیگز، Open Graph، JSON-LD، robots.txt، sitemap.xml۔

## 3. استعمال شدہ ٹیکنالوجی

خالصتاً **HTML5 + CSS3 + Vanilla JavaScript**۔ کوئی React/Vue/Angular، کوئی بیک اینڈ، کوئی ڈیٹا بیس، کوئی تصدیقی نظام اور کوئی بیرونی JS لائبریری استعمال نہیں کی گئی۔ یہ ایک مکمل جامد (static) ویب سائٹ ہے۔

## 4. فولڈر کی ساخت

```
islam-science-learning-hub/
├── index.html, syllabus.html, topics.html, mcqs.html,
│   short-questions.html, essay-questions.html, revision.html,
│   about.html, search.html, 404.html
├── topics/topic-01.html … topic-15.html
├── assets/
│   ├── css/ (style.css, responsive.css, print.css)
│   ├── js/  (main.js, navigation.js, search.js, quiz.js, browse.js)
│   ├── fonts/ (JameelNooriNastaleeq.woff2 — لائسنس یافتہ فائل خود شامل کریں، دیکھیں fonts/README.md)
│   └── images/ (logo.svg, favicon.svg, og-image.svg)
├── data/ (topics.js, mcqs.js, short-questions.js, essay-questions.js, revision.js)
├── source-documents/ (اصل 15 Word/PDF/Markdown ماخذ فائلیں + README)
├── robots.txt, sitemap.xml, .gitignore, README.md (یہ فائل)
```

`browse.js` اضافی فائل ہے (تجویز کردہ ساخت میں شامل نہیں تھی) جو مختصر سوالات، مقالہ سوالات، دہرائی اور تمام موضوعات کے صفحات پر فلٹر/تلاش کی مشترکہ منطق رکھتی ہے، تاکہ کوڈ غیر ضروری طور پر دہرایا نہ جائے۔

## 5. مقامی طور پر کیسے چلائیں (Run Locally)

کسی بھی سادہ اسٹیٹک سرور کی ضرورت ہے، مثلاً:

```bash
cd islam-science-learning-hub
python3 -m http.server 8000
# پھر براؤزر میں کھولیں: http://localhost:8000
```

یا Node کے ساتھ: `npx serve .`

صرف `index.html` کو براہِ راست فائل سسٹم سے (`file://`) کھولنا بھی زیادہ تر حصوں میں کام کرے گا، مگر بہتر تجربے کے لیے مقامی سرور کا استعمال تجویز کیا جاتا ہے۔

## 6. GitHub Pages پر ڈیپلائے کرنا

1. اس فولڈر کے مکمل مواد کو ایک GitHub ریپوزیٹری میں پش کریں۔
2. ریپوزیٹری کی Settings → Pages میں جائیں۔
3. Source میں "Deploy from a branch" منتخب کریں اور مین برانچ (`main` یا `master`) اور روٹ فولڈر (`/`) منتخب کریں۔
4. محفوظ کریں — چند منٹ میں سائٹ `https://alhayatacademy.github.io/Islam-Science/` پر دستیاب ہوگی۔
5. `robots.txt`، `sitemap.xml` اور تمام صفحات کے کینونیکل/OG ٹیگز میں یہ ڈومین پہلے ہی سیٹ کر دیا گیا ہے۔

## 7. Cloudflare Pages پر ڈیپلائے کرنا

1. Cloudflare Pages ڈیش بورڈ میں "Create a project" → اپنی GitHub ریپوزیٹری منتخب کریں۔
2. Build کمانڈ خالی رکھیں (کوئی بلڈ اسٹیپ درکار نہیں)۔
3. Build output directory کو روٹ (`/`) رکھیں۔
4. Deploy پر کلک کریں — سائٹ ایک `*.pages.dev` ڈومین پر دستیاب ہوگی، جسے چاہیں تو کسٹم ڈومین سے بھی جوڑا جا سکتا ہے۔

## 8. سائٹ کا مرکزی URL کہاں تبدیل کریں

`robots.txt`، `sitemap.xml` اور ہر صفحے کے `<link rel="canonical">` اور Open Graph ٹیگز میں فی الحال placeholder ڈومین `https://alhayatacademy.github.io/Islam-Science` استعمال ہوا ہے۔ حقیقی ڈیپلائمنٹ سے پہلے اسے اپنے اصل ڈومین سے بدل دیں (یہ تبدیلی `render.py` جیسی اسکرپٹ استعمال کرنے کی صورت میں `SITE_URL` ویری ایبل میں مرکزی طور پر کی جا سکتی ہے، یا ہر فائل میں براہِ راست تبدیل کریں)۔

## 9. نیا موضوع کیسے شامل کریں

1. `topics/topic-16.html` جیسی فائل کو کسی موجودہ topic صفحے کی کاپی بنا کر تیار کریں، ہیڈر/فوٹر اور کلاسز کو برقرار رکھیں۔
2. `data/topics.js` میں نئے موضوع کا اندراج (num، title، slug، intro، keywords، articleText) شامل کریں۔
3. اگر MCQs، مختصر سوالات یا مقالہ سوال شامل کرنا ہو تو متعلقہ `data/*.js` فائلوں میں نئے آبجیکٹس شامل کریں (نیچے دیکھیں)۔
4. `sitemap.xml` میں نئے صفحے کا URL شامل کریں۔

## 10. نئے MCQs کیسے شامل کریں

`data/mcqs.js` میں `window.MCQS` آرے میں ایک نیا آبجیکٹ شامل کریں:

```js
{
  id: "topic-01-mcq-021",
  topic: 1,
  question: "سوال یہاں لکھیں",
  options: ["اختیار اول", "اختیار دوم", "اختیار سوم", "اختیار چہارم"],
  answer: 0, // درست جواب کا انڈیکس (0 = پہلا آپشن)
  explanation: "درست جواب کی مختصر وضاحت"
}
```

## 11. مختصر سوالات کیسے ترمیم کریں

`data/short-questions.js` میں `window.SHORT_QUESTIONS` آرے میں موجود آبجیکٹس میں `question` اور `answer` فیلڈز ترمیم کریں، یا نیا آبجیکٹ (`id`, `topic`, `question`, `answer`) شامل کریں۔

## 12. دہرائی کے نوٹس کیسے ترمیم کریں

`data/revision.js` میں `window.REVISION` آرے میں متعلقہ موضوع کے `summary` اور `keyTerms` فیلڈز میں ترمیم کریں۔

## 13. فونٹ کی تنصیب

تفصیلی ہدایات `assets/fonts/README.md` میں موجود ہیں۔ خلاصہ: لائسنس یافتہ `JameelNooriNastaleeq.woff2` فائل کو `assets/fonts/` میں رکھ دیں؛ فائل موجود نہ ہونے کی صورت میں سائٹ خود بخود `Noto Nastaliq Urdu` یا عام serif فونٹ پر منتقل ہو جاتی ہے اور مکمل قابلِ استعمال رہتی ہے۔

## 14. مواد کے جائزے کی پالیسی (Academic Content Review Policy)

- تمام مضامین، سوالات اور مراجع اصل Word دستاویزات سے بغیر کسی حذف یا اضافے کے (سوائے ویب فارمیٹنگ کے) لیے گئے ہیں۔
- کوئی نئی قرآنی آیت، حدیث، حوالہ، اقتباس یا سائنسی دعویٰ شامل نہیں کیا گیا۔
- "تعلیمی مقاصد" اور "اہم تصورات" جیسے سیکشنز خود دستاویز کی اپنی سرخیوں سے تیار کیے گئے ہیں، من گھڑت مواد سے نہیں۔
- ہر موضوع کے مقالہ سوال کا مکمل امتحانی جواب (essay-questions.html) اسی موضوع کے مضمون، سرخیوں، مختصر سوالات اور خلاصے سے ترتیب دیا گیا ہے، تاکہ کوئی نیا غیر مصدقہ دعویٰ شامل نہ ہو۔
- **موضوع 8** کی ایک اضافی Markdown نقل (`source-documents/topic-08-alt.md`) اور **موضوع 1** کی ایک اضافی PDF نقل (`source-documents/topic-01.pdf`) بھی موصول ہوئیں۔ دونوں کا موازنہ اصل Word دستاویز سے کیا گیا اور وہ مکمل طور پر مماثل پائی گئیں؛ Word دستاویز کو حتمی ماخذ سمجھا گیا۔
- **موضوع 15** کی Word دستاویز ابتدائی اپ لوڈ کے دوران موصول نہیں ہوئی تھی، اور اس کمی کو ویب سائٹ کے پہلے نسخے میں شفاف طور پر ظاہر کیا گیا تھا۔ صارف نے بعد ازاں مصدقہ دستاویز فراہم کی، جسے دیگر تمام موضوعات جیسے ہی طریقہ کار سے پراسیس کر کے ویب سائٹ میں مکمل طور پر شامل کر دیا گیا ہے۔ اب موضوع 15 بھی دیگر 14 موضوعات کی طرح مکمل ہے۔

## 15. معلوم حدود (Known Limitations)

- Jameel Noori Nastaleeq فونٹ فائل شامل نہیں (لائسنسنگ کی وجہ سے)؛ فال بیک فونٹ استعمال ہوتا ہے۔
- یہ سائٹ مکمل طور پر برائوزر میں دستی طور پر (manual QA) جانچی گئی ہے: تمام صفحات، لنکس اور ڈیٹا فائلوں کی سکرپٹ سے خود کار جانچ کی گئی (نیچے سیکشن 16 دیکھیں)، البتہ حقیقی صارف کی مکمل براؤزر سیشن ٹیسٹنگ (مثلاً اصل موبائل ڈیوائسز پر) نہیں کی گئی۔
- تلاش کا نظام سادہ سب سٹرنگ میچنگ پر مبنی ہے (کوئی fuzzy search یا اسٹیمنگ شامل نہیں)، جو ایک مکمل جامد سائٹ کے لیے مناسب ہے مگر بہت بڑے ڈیٹا سیٹ کے لیے مثالی نہیں۔
- سائٹ کا مرکزی URL (`SITE_URL`) `https://alhayatacademy.github.io/Islam-Science` پر سیٹ ہے (سیکشن 8 دیکھیں)۔

## 16. QA/ٹیسٹنگ کا خلاصہ

- تمام 15 topic صفحات، تمام نیویگیشن لنکس، CSS اور JS پاتھز خود کار اسکرپٹ سے چیک کیے گئے — کوئی ٹوٹا ہوا لنک نہیں ملا۔
- تمام JS ڈیٹا فائلوں (`data/*.js`) کی syntax `node -c` سے تصدیق کی گئی۔
- ہر صفحہ `lang="ur"` اور `dir="rtl"` استعمال کرتا ہے۔
- 300 MCQs (15 × 20) اور 105 مختصر سوالات (15 × 7) کی ساخت پروگرام کے ذریعے تصدیق کی گئی کہ ہر MCQ کے ٹھیک 4 آپشنز اور ہر سوال کا جواب/وضاحت خالی نہیں۔
- براؤزر کے اندر مکمل صارف سیشن (کلک کرکے کوئز مکمل کرنا وغیرہ) کی دستی جانچ اس ماحول میں براؤزر کی عدم دستیابی کی وجہ سے ممکن نہیں تھی؛ اس کی بجائے JS منطق کا مکمل کوڈ ریویو کیا گیا۔

## 17. مستقبل میں بہتری کی تجاویز

- Jameel Noori Nastaleeq (یا Noto Nastaliq Urdu) فونٹ فائل کو باقاعدہ طور پر لائسنس کے ساتھ شامل کرنا۔
- تلاش کے نظام میں ہلکی fuzzy matching شامل کرنا۔
- ہر موضوع کے لیے مختصر آڈیو/ویڈیو خلاصہ شامل کرنے کا امکان (اختیاری، سائٹ کی سادگی کو متاثر کیے بغیر)۔
- صارف کی پیش رفت (کون سے MCQs حل ہوئے) کو مقامی طور پر یاد رکھنے کے لیے ہلکا localStorage استعمال کرنا (فی الحال شامل نہیں تاکہ سائٹ سادہ اور بغیر کسی اسٹیٹ مینجمنٹ کی پیچیدگی کے رہے)۔
